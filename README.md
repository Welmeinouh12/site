# Nexora Market

Site vitrine en HTML, CSS et JavaScript natifs. L'arabe et le sens RTL sont activés par défaut. Le bouton de langue bascule l'ensemble du site en français/LTR.

## Utilisation

Ouvrez `index.html` dans un navigateur. Aucun framework, installation ou serveur n'est nécessaire.

## Images à ajouter

Les fichiers sont lus directement depuis le dossier `images/`. Le logo fourni est déjà placé dans `images/logo.png`. Ajoutez les images suivantes en conservant exactement ces noms :

| Fichier | Image à placer |
| --- | --- |
| `banner.jpg` | Grande photo de bannière |
| `product1.jpg` | Draâra |
| `product2.jpg` | Melhfa |
| `product3.jpg` | Chaussures |
| `product4.jpg` | Sac |
| `product5.jpg` | Sandales |
| `product6.jpg` | Melhfa |
| `product7.jpg` | Accessoire, par exemple une montre |
| `product8.jpg` | Draâra |
| `category1.jpg` | Image de catégorie vêtements |
| `category2.jpg` | Image de catégorie chaussures |
| `category3.jpg` | Image de catégorie sacs et accessoires |

Le panier, la recherche, les filtres et la fiche produit sont des démonstrations côté navigateur ; aucune commande n'est envoyée.
